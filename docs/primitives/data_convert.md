# data.convert

_Convertit un fichier entre tous formats supportés (CSV, JSON, Parquet, JSONL/NDJSON) par auto-détection des extensions source et destination._

## Parametres

| Parametre | Type | Requis | Defaut | Description |
|-----------|------|--------|--------|-------------|
| source | string | **Oui** | — | Le chemin du fichier source (format auto-détecté par extension). |
| destination | string | **Oui** | — | Le chemin du fichier de destination (format auto-détecté par extension). |
